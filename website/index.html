01 / OVERVIEW

Understanding the project

Prompt injection is a security challenge where untrusted text attempts to influence an AI model to ignore or override its intended instructions. This lab compares model behavior across controlled test scenarios.

01

Baseline testing

Run control and injection scenarios against the model without the tested mitigation.

02

Mitigation testing

Evaluate a mitigation approach using the same core task and scoring criteria.

03

Unseen cases

Check performance on additional test cases that were not part of the initial set.

04 / RESPONSIBLE EVALUATION

What these results do—and don't—tell us

The experiments demonstrate a repeatable testing workflow, not a comprehensive security certification. Broader evaluation should include more attack variants, repeated runs, additional models, and independent validation of the scoring criteria.
